1. 버튼 반응성 문제 해결 (v0.2.5)
=====================================================================

문제점:
- 액션 버튼 클릭 시 반응 지연 및 무반응 현상
- 연속 클릭 시 이벤트 처리 불안정
- setTimeout 지연으로 인한 UX 저하

해결책:
1) setTimeout 최적화
   - 포커스 지연: 100ms → 50ms로 단축
   - 모달 포커스 반응성 개선

2) 이벤트 위임 개선
   - 기존: 수동 parentElement 체크
   - 개선: closest('.action-btn') 메서드 사용
   - 중첩된 SVG 요소 처리 개선

3) UI-First 접근법 구현
   - 즉시 UI 업데이트 → 백그라운드 비동기 작업
   - Promise.all()로 병렬 처리 (addLog + saveTasks)
   - 메인 스레드 블로킹 방지

4) 스로틀링 시스템 추가
   - actionThrottleMap으로 중복 클릭 방지
   - 알림/하이라이트: 100ms 스로틀링
   - 이동 액션: 200ms 스로틀링 (신중한 액션)

수정된 파일:
- renderer.js: 이벤트 위임, UI-First 로직, 스로틀링 시스템

   - escapeTsvValue() 함수로 탭/줄바꿈 처리
   - 탭 → 공백, 줄바꿈 → 공백으로 치환

4) EDIT 액션 수정
   - "Task modified" → 실제 taskData.content 사용

5) 완료 카운터 업데이트
   - TSV 파일에서 COMPLETE 액션 카운팅
   - 탭 구분자 기반 파싱

5. 기술적 세부사항
=====================================================================

이벤트 위임 개선:
```javascript
// 기존
if (e.target.classList.contains('action-btn') || e.target.parentElement.classList.contains('action-btn'))

// 개선
const button = e.target.closest('.action-btn');
```

UI-First 패턴:
```javascript
// 즉시 UI 업데이트
this.renderTasks();

// 백그라운드 비동기 작업
Promise.all([
    this.addLog(action, task, task.content),
    this.saveTasks()
]).catch(error => console.error('Background save failed:', error));
```

TSV 데이터 형식:
```
2025-07-26T12:25:28	NOTI_ON	OVERDUE	task-id...	2025-07-26 11:49	2025-07-26 12:00	#[RED]test	waerewa,dfssdf,trsdrt
```

스로틀링 시스템:
```javascript
isActionThrottled(actionKey, throttleMs = 100) {
    const now = Date.now();
    const lastAction = this.actionThrottleMap.get(actionKey);
    
    if (lastAction && (now - lastAction) < throttleMs) {
        return true; // 스로틀 중
    }
    
    this.actionThrottleMap.set(actionKey, now);
    return false; // 실행 허용
}
```
