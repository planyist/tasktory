    About Tasktory

    View History

    How to Use

    • Add Task: Click icon or press Ctrl+N
    • Select: Click anywhere in a row, chips included. Double-click a row to open it for editing
    • Edit: Select one row, then click in the bar above the table
    • Complete: Click in the bar. You are asked to confirm, and can set the completion time
    • Delete: Click in the bar. Deleting a repeating row deletes its repeat rule too
    • Highlight: Click in the bar. With several rows selected, a mixed selection is highlighted as a whole
    • Reorder: Use arrows to change task order
    • Export/Import: Open Settings and use the Export and Import buttons
    • Tags: Use #hashtags separated by spaces (e.g., #work #urgent)
    • Sorting: Click a time header to sort by it
    • Attachments: Drop files on the edit form. The file is linked, never copied
    • Always on top: On by default. The pin at the top right turns it off and on
    • Notifications: Click icon to toggle task notifications

    Notifications

    • Auto Alerts: 1 hour and 15 minutes before deadline
    • Overdue Alert: When task passes target time
    • Toggle Per Task: Select rows and use the bell in the bar. A muted task is marked next to its target time
    • Default Setting: Configure in Settings icon

    Task Status

    • Pending: Task is waiting to be started
    • In Progress: Task is currently being worked on
    • Due Soon: Inside the notification lead time
    • Overdue: Task has passed target time
    • Completed: Task has been finished
    • Ongoing: No target time. Never overdue or due soon, and raises no notifications

    Views

    • List: The table. Everything you can do to a task happens here
    • Calendar: A month grid, toggled from the buttons at the top right. A task sits on its target day, and one with no target time sits on its start day. View-only - nothing in a cell is clickable
    • Side strip: Ctrl+M. Read-only, always on top. In calendar view it stands up a single day - today, or the next day with work if today is clear

    Search and Filters

    • Search a column: The dropdown beside the search box narrows the search to one column
    • Chips: A chip in a row is part of the row - clicking one selects it. Filtering is the quick filters job
    • Quick filters: The row under the search box lists the statuses and tags actually in use, up to ten. All clears the search and the column

    Repeating Tasks

    • One row is the rule: Set a repeat in the task edit form. Completing it does not remove the row - the dates move to the next occurrence
    • One step at a time: A task overdue by five occurrences takes five presses, and each is logged. To skip ahead, edit the date
    • Deleting: Deleting the row deletes the repeat rule with it
    • Target time required: A task with no target time cannot repeat

    Keyboard Shortcuts

    • Ctrl+N: Add new task
    • Ctrl+M: Collapse to the side strip
    • ESC: Close modal or date picker

    Completion Counter

    The completion counter shows the number of tasks completed today, based on completion records in the daily history log files.
